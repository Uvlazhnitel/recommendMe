# Personal Movie Recommender — документы для разработки

**Статус:** проектирование завершено; реализация MVP ещё не началась.  
**Дата фиксации требований:** 2026-10-25.  
**Назначение:** личное веб-приложение для поиска полнометражного кино, которое с высокой вероятностью понравится владельцу на **80/100 и выше**. Это цель оптимизации, **не гарантия**.

## Что должно получиться

- Открывается в браузере на компьютере и телефоне; разворачивается на **домашнем сервере**.
- Содержит три раздела: **Рекомендации**, **Оценить фильм**, **Библиотека**.
- **Один раз** читает существующие CSV Letterboxd через скрипт разработчика — **без экрана импорта**.
- Дальше позволяет искать фильмы по TMDB, отмечать просмотренными, ставить/исправлять оценки **целым числом от 0 до 100**.
- Сохраняет оценки и учитывает их уже при следующей подборке.
- Даёт до пяти проверенных, не просмотренных полнометражных фильмов с персональным обоснованием; не предлагает случайные малоизвестные фильмы ради совпадения тегов.

## Как начать работу в Codex

1. Создать новый репозиторий/папку проекта и положить туда **все эти Markdown-файлы в корень**.
2. Разместить `ratings(6).csv` и `watched(6).csv` в локальной `data/import/` (либо указать их абсолютные пути скрипту). Это **личные данные**: `data/` добавить в `.gitignore`, не загружать CSV в публичный репозиторий.
3. Передать Codex следующий запрос:

> Прочитай AGENTS.md, PROJECT_SPEC.md, IMPLEMENTATION_PLAN.md, RECOMMENDER.md, DATA_AND_DEPLOYMENT.md и PROGRESS.md. Выполни **только фазу 1** из IMPLEMENTATION_PLAN.md: минимальный Next.js + SQLite + Docker Compose, однократное наполнение базы из двух Letterboxd CSV через backend-скрипт. Не реализуй рекомендации и UI следующих фаз. Выполни тесты, сверь счётчики импорта, обнови PROGRESS.md и кратко сообщи результат.

4. Следующие задачи запускать по **одной фазе**, после проверки результатов предыдущей.

**Важно:** этот пакет — документация и инструкции. Программный код приложения, `Dockerfile`, `compose.yaml`, `.env.example` и скрипты импорта должен **создать Codex** в ходе соответствующих фаз. Здесь не утверждается, что приложение уже работает.
