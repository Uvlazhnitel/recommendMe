# Фаза 4 — итоговая UX-приёмка

Дата: 2026-10-27. Проверяются завершённые 4.1–4.4 и точечные исправления 4.5.

## Среда и метод

Production Next.js 16 / React 19, отдельный localhost-порт 45152, Chrome через установленный Playwright. Встроенный CUA дополнительно использован для просмотра настоящего экрана. Проверены ширины 375, 430, 768, 1024 и 1440 px; touch — эмуляция 430 px. Новых зависимостей нет.

Синтетическая SQLite начинается с 830 просмотров, согласованного снимка профиля и импортированных полей Letterboxd. Сценарий использует настоящие страницы, HTTP и SQL. OpenAI/TMDB подменены только в дочернем тестовом процессе; изображения читаются из уже имеющихся подтверждённых assets. Неизвестные внешние запросы запрещены, используются только фиктивные настройки. Реальные OpenAI/TMDB API-вызовы: **0 / 0**. Возвращаемый mock usage не является расходом аккаунта.

Повторный запуск:

```sh
npm run build
npm run test:ux -- --playwright-path /path/to/existing/playwright --port 45152 --output /tmp/recommendme-phase4-evidence
npm run test:db
npm run lint
npm run typecheck
git diff --check
```

Если Playwright доступен как обычный локальный модуль, `--playwright-path` можно опустить. Пакеты/браузеры автоматически не устанавливаются. Занятый порт вызывает отказ, чужой процесс не останавливается. Скриншоты и results.json сохраняются вне репозитория; временная база, backup и journal удаляются в finally. Рабочие файлы проверяются до/после чтением и хешированием.

## Карта покрытия

| Требование | Фактическое подтверждение |
| --- | --- |
| Единый путь рекомендация → просмотр → библиотека → оценка → рекомендации | test:ux, настоящие HTTP/SQLite, 90 / NULL / 0; сохранённые объяснения и история остаются |
| Подтверждение оплаты, отмена, загрузка, предыдущая выдача | Браузер: Escape, двойной клик, параллельный POST, переключение, два успешных цикла и старые строки истории |
| Идемпотентность и перезапуск | Повтор request_id, reload во время обработки, production restart без дополнительных provider calls |
| Отклонение/undo | Браузер + SQL: текущий запрет снимается, historical rejected остаётся, оценки/просмотры не меняются |
| Ошибки провайдера, invalid/refusal/incomplete, нет кандидатов | Настоящий HTTP-конвейер с mock fetch; прежняя подборка сохранена, автоматического повтора нет |
| Backup/SQL rollback/save_only=1 | Отказ каталога backup до оплаты; SQL trigger прерывает транзакцию после подготовки. Повтор сохранения через UI без новых OpenAI/TMDB-запросов |
| Дедлайн и межпроцессная блокировка | recommendation-screen.test.ts: управляемый таймер, AbortSignal и отдельный процесс; блокировка сохраняется до завершения сетевой операции |
| Сообщение тайм-аута в UI | Отдельная симуляция HTTP 504; это не ожидание реальных 15 минут в браузере |
| Потеря связи после записи | Реальный PATCH и прерванный следующий GET: читающее восстановление без повторной записи |
| Поиск и каталог | Название/год/версии, пустой и ошибочный TMDB, possible_duplicate, просмотр 100, повтор без изменения timestamps |
| Библиотека | Все страницы через серверную пагинацию 25; кириллица/латиница, фильтры/4 сортировки, URL/reload/Back/Forward, страница 8/scroll, исчезновение последней страницы и запоздавшая выдача |
| Пустая библиотека | Симуляция ответа read-only API проверяет сообщение и переход к оцениванию; основная цепочка использует настоящую SQLite |
| Оценки и свежий вкус | 90→40→NULL, реальный 0, порог обновления и неизменный профиль. library-ui/workflow/recommendation-memory tests проверяют оба следующих контекста, cleared/added и точный порог 9/10 |
| Безопасность HTTP | Origin 403 без записи, invalid параметры, no-store, production preview 404. Дополнительные границы всех write routes — workflow.test.ts |
| Сохранность данных | SHA-256 пользовательских файлов и четырёх таблиц до/после; integrity_check=ok, foreign_key_check пустой. Синтетические исходные поля фильма/Letterboxd и профиль также сравниваются |

## Визуальный и accessibility-аудит

Просмотрены утверждённые desktop/mobile Cinema Spotlight и скриншоты всех трёх разделов, диалога, ошибки и пустых состояний. Сверены graphite/tangerine, Manrope и иерархия, контейнер/отступы, постеры 2:3, кнопки, навигация и мобильная композиция. Новых визуальных концепций нет. Согласованные ранее настоящие TMDB-изображения и английские объяснения отличаются от русских демонстрационных текстов концепции; буквальное совпадение текстового объёма не заявляется.

Проверены Tab/Shift+Tab, Escape и возврат фокуса, aria-current/aria-pressed, labels/status/alert, slider Home/End/стрелки и точный ввод. Черновик не сохраняется сам. На пяти ширинах нет горизонтального скролла; отдельно проверены длинное название, отсутствующее изображение, длинное объяснение, увеличенный текст, reduced motion и touch. Доступность проверена практически; полной сертификации WCAG или проверки экранным диктором не заявляется.

Производительность: начальная библиотека выполняет два list GET (страница и total с limit=1), без N+1 деталей и клиентской загрузки 830 записей. Постеры имеют заданные пропорции; заметных скачков из-за изображений не обнаружено при просмотре. No-store сохранён. Абстрактные микрооптимизации и новый кеш не добавлялись.

## Доказательства и итог

Скриншоты в каталоге локального запуска (в текущей приёмке — qa-45, вне Git): recommendations-desktop/mobile, rate-desktop/mobile, library-desktop/mobile, library-details-mobile, generation-confirmation, generation-error и recommendations-empty. Дополнительные снимки показывают отсутствие изображений и пустую библиотеку. results.json хранит перечень проверок, размеры, контраст, mock-счётчики и результат защиты данных; он не содержит профиля или реальных ключей.

- `npm run test:db`: **192/192**, без ошибок.
- `npm run test:ux`: **24 составные проверки**, passed; пять размеров, ошибок приложения нет. Намеренные HTTP/network failures выделены как ожидаемые, а не необработанные ошибки UI.
- `npm run lint`, `npm run typecheck`, production build, итоговый `tsc --noEmit` и `git diff --check`: успешно.
- Четыре проверенные пары контраста: 17,49 / 9,14 / 8,35 / 7,07, все выше 4,5. Это проверка основных цветов, не полная автоматическая сертификация.
- Счётчики одного полного прогона: **11 OpenAI-моков / 44 TMDB-мока**, реальные вызовы **0 / 0**. Обычный успешный цикл по-прежнему содержит два запроса OpenAI.
- SHA-256 рабочей SQLite, четырёх таблиц, обоих CSV и .env.local совпал с исходным снимком; схема 3, 830 просмотров / 519 оценок, профиль и пустая рабочая история сохранены. Рабочая база не мигрировалась.
- Проверены публикуемые файлы и клиентские ассеты на реальные значения настроенных ключей и личные артефакты: утечек нет.
- Остались два прежних предупреждения Turbopack о динамическом файловом доступе в db.ts/migrations.ts. Новых предупреждений сборки нет.

**Вердикт: 4.5 и фаза 4 завершены в рамках локальной UX-приёмки.** Прототип готов к отдельно разрешённой фазе 5. Docker, настройка сети и развёртывание не начинались. Физические Safari/iPhone, screen reader, реальные задержки/доступность провайдеров и содержательное качество новых live-рекомендаций этой приёмкой не подтверждаются.
