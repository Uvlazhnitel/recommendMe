## Подфаза 1.1 — создание проекта — 2026-10-25

- [x] Минимальный Next.js App Router + TypeScript (strict), npm и ESLint; стартовая страница Movie Recommender, обычный CSS.
- [x] SQLite через `better-sqlite3`, отдельный Node-only модуль `src/lib/db.ts`; ленивое открытие, создание родительского каталога и явное закрытие соединения вызывающим кодом.
- [x] `DATABASE_PATH`: абсолютный либо относительно корня проекта; по умолчанию `./data/movies.sqlite`. Пустой путь и `:memory:` отклоняются. Основная база не содержит таблиц.
- [x] `.env.example`: DATABASE_PATH, TMDB_API_KEY, OPENAI_API_KEY, OPENAI_MODEL. Внешние ключи необязательны; интеграций и SDK нет. CLI загружает окружение через `@next/env`; значения не экспортируются в браузер. Health route помечен `server-only`, модуль БД использует Node.js fs.
- [x] Динамический `GET /api/health`: SELECT 1, HTTP 200/503, Cache-Control: no-store, без раскрытия путей и внутренних исключений.
- [x] Команды `dev`, `build`, `start`, `typecheck`, `lint`, `db:check`, `test:db`; зависимости зафиксированы package-lock.json.

**Технические решения:** Next.js 16.4.3, React 19.3.1, better-sqlite3 13.0.3, TypeScript 6.0.3; без ORM и дополнительных сервисов. Для better-sqlite3 требуется Node.js >=22; фактически проверено на Node.js 26.11.1 / npm 11.20.0. `dev` и `start` по умолчанию слушают 127.0.0.1. Приоритет текущего запроса: Docker, импорт и прикладная схема отложены; прежний общий план фазы 1 не означает их реализацию в 1.1.
